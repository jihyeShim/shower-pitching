# Shower Pitching

Forget the elevator pitch. Pitch VCs from a shower while they soak in a hot tub.
Your water is the mood of the room: buzzwords make it cold, real numbers warm it back up.

Built in one day at Showerhacks (San Francisco, 2026-09-26).

- Play: https://shower-pitching.vercel.app

## How it works

- A three.js shower room seen from inside the stall, with a custom wet-glass shader.
- Your webcam face in a window with a live MediaPipe shower filter.
- Live captions from the Web Speech API. Buzzword detection runs in the browser, so reactions are instant.
- Buzzwords drop the water 6°C, real numbers (paying, revenue, retention, percent) raise it 5°C.
- VCs interrupt with sharp questions generated by Featherless AI (Qwen3). End at 20°C or warmer to get funded.

## Run locally

```bash
npx netlify-cli dev --port 8890   # serves public/ and the functions in netlify/functions
```

Create `.env` with `FEATHERLESS_API_KEY=...` to get live VC lines. Without a key the functions return scripted lines.
Open `http://localhost:8890/?debug=1` for debug keys (S start, B buzzword, V interject, F frozen, W funded, R restart).

## Deploy

Vercel: `api/*.mjs` wraps the same handlers. Set `FEATHERLESS_API_KEY` in the project's environment variables.

## Layout

- `public/js/state.js` game flow, `public/js/config.js` all numbers and word lists, `public/js/characters.js` the six VCs
- `public/js/scene/` 3D room, face filter, VCs, ice, endings
- `public/js/voice/` speech recognition, buzzword detection, sounds, HUD
- `netlify/functions/`, `api/` server functions for VC lines and the ending letter

All VCs and firms are fictional. The satire is aimed at pitch culture, not at any real person.
